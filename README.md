# Football Career – Android Starter

Echter Android-Projektstarter mit spielbarem Vertical Slice:
Karriere-Hub, Spielerprofil, Kalender, Training, Match-Simulation und News.

Noch nicht vollständig: animierte 2D-Pitch-Engine, vollständige Welt-/Club-Datenbank, KI-Welt, Transfers, Finanzen, Nationalteams und Trainerkarriere. Diese werden modular ergänzt.

In Android Studio öffnen, Gradle synchronisieren und auf Gerät/Emulator starten.
